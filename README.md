# Task 3 - Basic Vulnerability Scan on My PC

## Objective
The objective of this task was to perform a basic vulnerability assessment on a local machine using a free vulnerability scanning tool and identify potential security risks.

## Tool Used
- Nessus Essentials

## Target System
- Localhost (127.0.0.1)
- Operating System: macOS

## Steps Performed
1. Installed Nessus Essentials.
2. Configured the target as localhost (127.0.0.1).
3. Started a full vulnerability scan.
4. Waited for the scan to complete.
5. Reviewed identified vulnerabilities and severity levels.
6. Researched mitigation techniques for detected vulnerabilities.
7. Documented the most critical findings.
8. Collected screenshots of scan results.

## Vulnerability Summary

| Severity | Description |
|-----------|-------------|
| High | Missing security updates |
| Medium | SSH service enabled |
| Medium | Weak SSL/TLS configuration |
| Low | Open network ports |
| Informational | System and service information |

## Remediation Recommendations
- Install all available security updates.
- Disable unused services and ports.
- Enable firewall protection.
- Use strong authentication methods.
- Keep software and applications updated.
- Perform regular vulnerability assessments.

## Files Included
- Vulnerability_Report.pdf
- Scan screenshots
- README.md

## Outcome
The vulnerability scan successfully identified potential security weaknesses on the local system. Appropriate mitigation measures were researched and documented to improve the overall security posture of the machine.
